AKIRA 16.3.2 — Corrección de primer arranque en Windows

PROBLEMA: Al abrir el AKIRA.exe portable, buscaba C:\Users\<usuario>\akira_config.json y fallaba con FileNotFoundError.

CAMBIOS:
* Las compilaciones portables guardan sus datos en %LOCALAPPDATA%\AKIRA, sin usar el directorio principal del usuario.
* Si no hay configuración, AKIRA crea una inicial en modo OBSERVE y sin cuenta autorizada.
* Nunca reescribe una configuración que ya existe (aunque sea inválida).
* El workflow de Windows prueba el arranque sin configuración y sin --app-root antes de publicar el ejecutable.
* Los instaladores antiguos con --app-root siguen admitidos.

PARA SUBIR: Extrae el contenido de este ZIP dentro de tu carpeta GitHub Desktop "akira" y acepta reemplazar; no metas una carpeta extra dentro. GitHub Desktop -> Commit to main -> Push origin. En Actions lanza un Run workflow NUEVO sobre main. Descarga el nuevo build (no re-run del commit antiguo).

NO modifica la estrategia ni elimina operaciones de MT5; no contiene instalador final ni modelo de IA.
